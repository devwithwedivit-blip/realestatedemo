# Estate Consultants — Real Estate Portal

> **Consulting real estate solutions & results since 1992**

A high-performance, human-crafted real estate portal designed for premium residential, commercial, and luxury properties in New Delhi and NCR.

---

## ✨ Features

- **🏛️ Interactive 3D Architectural Logo**: Built with pure vector SVG and a 3D isometric physics engine featuring dynamic pitch/yaw tilt, stereoscopic cantilever parallax, dynamic specular lighting reflections, and tactile spring feedback.
- **🎨 Custom Color System**:
  - **Primary Accent**: `#FF4885` (Vibrant modern rose pink / magenta coral)
  - **Global Background**: `#FFE8F0` (Soft blush canvas)
  - **Brand Typography**: Google Font **Outfit** & **Plus Jakarta Sans**
- **🔍 Advanced Property Search & Filter**:
  - Search by locality, property type, budget, and configurations.
  - Quick filter chips for South Delhi, Central Delhi, Luxury Floors, and NCR Enclaves.
- **⚖️ Side-by-Side 3-Way Property Comparison Engine**:
  - Compare up to 3 properties simultaneously across key metrics: price, sq.ft rates, carpet area, possession dates, RERA verification status, and amenities.
- **🧮 Interactive Home Loan EMI Calculator**:
  - Real-time loan amount, tenure, and interest rate sliders with instant breakdown of principal, interest, and monthly EMI.
- **📱 Fully Responsive Design**:
  - Dedicated slim utility bar with tap-to-call and regional selector.
  - Sticky navbar with sliding underline indicators.
  - Full-height mobile navigation drawer with touch gesture support.

---

## 🚀 Quick Start

To preview locally:

```bash
# Using Python
python -m http.server 8080

# Or using Node.js
npx serve .
```

Then open [http://localhost:8080/index.html](http://localhost:8080/index.html) in your browser.
